# Glyph Composite Toy

Единая игрушка для Nothing Phone (3): часы в центре, пульсирующее внешнее кольцо, дуга зарядки и боковой индикатор уведомления.

## Сборка

1. Скачайте `glyph-matrix-sdk-2.0.aar` из официального репозитория Nothing и положите в `app/libs/`.
2. Откройте проект в Android Studio.
3. Соберите `assembleRelease`.
4. Опубликуйте APK/проект в публичном GitHub-репозитории и вставьте GitHub-ссылку в Nothing Playground.

Официальный SDK указывает Phone (3) как устройство `Glyph.DEVICE_23112` с матрицей 25×25.
