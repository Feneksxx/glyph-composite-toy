# Glyph Composite Toy

A Nothing Phone (3) Glyph Toy for the 25×25 Glyph Matrix.

Features:

- clock with selectable pixel styles;
- music visualizer;
- charging and battery indicators;
- notification animation;
- volume indicator;
- brightness controls;
- Russian and English interface.
